# Funcionalidades do MVP

| --- | --- | --- |

| Configuração do escritório | Dados do escritório, OABs monitoradas (sem logo própria) | — |

| Agenda | Audiências, reuniões, diligências por dia/semana/mês | Integração Google Agenda |
| Financeiro | Honorários, lançamentos, contas a receber, caixa | Recibos em PDF |
| Portal do cliente | Cliente final vê os próprios processos, com a marca advocacia.legal, só o que o advogado aprovar | Envio de documentos pelo cliente |
| Intimações DJEN | Busca diária por OAB, vínculo pelo número CNJ, marcação de lida | Sugestão automática de prazo |
